# Design: 动态权重 — 跌市方向因子加倍

## 背景

当前三因子权重固定为 50/20/30（量能/方向/份额），不区分市场环境。
跌市中，放量可能是恐慌抛售而非国家队买入，量能因子反而给出错误信号。
涨市中，ETF 跟涨无法区分是市场 β 还是国家队 α。

## 核心改动

`etf_signals.py` 的 `compute_cp()` — 唯一全局 CP 计算入口，根据 `idx_chg` 动态调整权重。

### 新权重逻辑

```
如果 大盘跌 (idx_chg < 0):
    W_VOL  = 0.35  (降低 — 跌市放量可能是抛售)
    W_DIR  = 0.35  (提高 — 跌市逆势才是真国家队)
    W_SHARE = 0.30  (不变)
否则 (大盘涨或平):
    W_VOL  = 0.50  (不变)
    W_DIR  = 0.20  (不变)
    W_SHARE = 0.30  (不变)
```

### 改动范围

| 文件 | 位置 | 改动 |
|------|------|------|
| `scripts/etf_signals.py` | `compute_cp()` 函数 | ~10行：加 idx_chg 判断，动态赋值权重常量 |

不改任何其他文件。`compute_cp` 被所有模块引用，一处改动全局生效。

## 影响分析

### 涨市（idx_chg ≥ 0）
行为与现在完全相同。所有历史回测结果不变。

### 跌市（idx_chg < 0）
- 逆势 ETF（大盘跌、ETF涨）：方向因子从 20→35 分，CP 提升约 15 分
- 跟跌 ETF（大盘跌、ETF 跟跌）：方向因子本身已很低，权重大小影响有限
- 放量跟跌 ETF：量能因子从 50→35 分，CP 降低约 15 分（正确过滤恐慌抛售）

### 近一月效果重算

过去一个月无跌市日，全部 5 次信号表现不变。

## 风险

- 回测结果需要重跑确认（涨市不变、跌市加权后是否有改善）
- 权重 35/35/30 是经验值，可能需要后续 Walk-Forward 验证最优值

## 测试

新增 `test_dynamic_weights.py`：
- 涨市下 CP 与固定权重一致（无回归）
- 跌市下方向因子权重生效
- 跌市下量能因子权重降低生效
